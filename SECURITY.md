| :--- | :--- |

## Reporting a Vulnerability
**DO NOT OPEN PUBLIC ISSUES FOR SECURITY DISCOVERIES.** If you detect a vulnerability, structural exposure, or parameter leak, please utilize GitHub's integrated **Private Vulnerability Reporting** gateway via the Security tab. Alternatively, contact our triage team securely at `security-triage@example.com`. We initial-ack all disclosures within 48 hours.
